Claude Remote Login

Connect a teammate’s Claude subscription without signing in on this computer. This is a standalone CLIProxyAPI plugin.

1. Authorize this page

Used only for requests to this proxy. It is not stored in the browser or sent to Claude.

2. Send the link to your teammate

They open this link on their own device and sign in with Microsoft SSO. They then copy the complete authorization code from the final page and send it back to you.

Open on this device

3. Connect the account

Use the code from this exact link. A code generated by a separate Claude Code login will not match.

Ready to generate a sign-in link.

Each link lasts 15 minutes. Account credentials are saved by the proxy and join its normal Claude account pool. The built-in OAuth page remains unchanged.
