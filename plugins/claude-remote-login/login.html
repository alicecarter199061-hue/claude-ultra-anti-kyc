Claude 远程授权登录

安全连接 Claude 订阅账号至网关号池，支持 1 年长效免刷新模式，彻底杜绝掉号。

1. 身份验证与登录模式

仅用于验证本网关管理权限，不会被浏览器持久化存储，亦绝不发送给第三方。

2. 前往 Claude 官方完成授权

⚠️ 防封提醒：请确保当前浏览器代理出口 IP 与本 CPA 网关服务器公网出口保持严格同源一致！

请点击下方按钮打开链接（或复制到挂了樱花代理的指纹浏览器中），登录账号并点击 [Authorize / 同意授权]。授权成功后，页面将展示一段授权码。

3. 回填授权码并完成连接

请务必使用上述链接授权后返回的专属 Code，其他独立登录生成的 Code 将无法匹配。

准备就绪，请点击上方按钮生成授权链接。

每个链接有效期为 15 分钟。成功连接后，凭据将自动保存至网关 auth/ 目录并即刻热加载上线。
